# HTML PPT Master

生成固定 1280×720 画布、深色蓝图风格的交互式 HTML 幻灯片。所有输出为单文件 HTML，可直接在浏览器打开演示。

## 设计规范

**色板**（禁止新增颜色）：
- 背景：`#05060f`（画布）/ `#0a0b14`（卡片）
- 主强调：`#663af3`（紫色，用于数字、序号、高亮、导航点）
- 标题文字：`#d8ecf8`（渐变标题）/ `#d1e4fa`
- 正文：`#c7d3ea`，次要：`#9da7ba`，注释/来源：`#6b7280`
- 状态色：`#4ade80`（上升/正面）、`#f87171`（下降/风险）、`#e87b52`（警告）

**字体**：正文 Inter/PingFang SC；数字、标签、kicker 用 JetBrains Mono 等宽。大标题用极细字重（200/300）+ 渐变文字。

**视觉元素**：80px 蓝图网格背景（径向渐隐）、顶部锥形光晕、玻璃拟态卡片（半透明+细边框+内外阴影）、1px 分隔线网格。

## 工作流程

1. **复制模板骨架**：读取 `assets/template.html`，以此为基础生成输出文件。模板已包含全部 CSS 和交互 JS，只需填充幻灯片内容。
2. **选择页面模板**：根据每页内容类型，从 `references/slide-templates.md` 中选择对应模板的 HTML 片段，替换 `<!-- SLIDES GO HERE -->` 区域。
3. **填充内容**：将用户素材填入对应结构，保持 class 名和层级不变。
4. **设置元信息**：修改 `<title>`、`.chrome-top .brand`、`.chrome-top .date`、`.chrome-bottom .series`、底部总页数 `/ XX`。
5. **输出**：保存为 `.html` 文件，通过 `present_files` 交付。

## 交互（已内置，无需修改）

- 键盘：← → 翻页，空格下一页，Home/End 跳首尾
- 鼠标滚轮：上下滚动翻页（600ms 节流）
- 触摸：左右滑动翻页
- 右侧圆点：点击跳转任意页
- 画布自动缩放适配窗口（保持 16:9 比例）
- 每页元素错峰淡入（`.stagger` 容器内子元素依次入场）

## 页面模板速查

| 模板 | class | 适用场景 |
|------|-------|---------|
| 封面 | `.s-cover-hero` | 开场/章节封面，全屏图+大标题 |
| 议程 | `.s-agenda` | 目录/导航，左右分栏列表 |
| 指标矩阵 | `.s-metrics` | KPI/数据总览，4列网格 |
| 三列卡片 | `.s-lines` | 分类展示，3列卡片+底部统计 |
| 双图表 | `.s-chart` | 数据可视化，左右SVG图表 |
| 精炼列表 | `.s-refine` | 要点详解，编号+标题+描述 |
| 对比表格 | `.s-comparison` | 方案/维度对比表 |
| 战略卡片 | `.s-brand` | 框架/能力/战略维度 |
| 结束页 | `.s-close` | 总结+行动建议，左右分栏 |

每种模板的完整 HTML 结构和填充要点见 `references/slide-templates.md`。

## 约束

- 画布固定 1280×720，不要修改 `#deck` 尺寸。
- 第一张幻灯片必须加 `active` 类，`data-slide` 从 0 递增。
- 需要入场动画的容器加 `class="stagger"`，不要给单个元素加。
- 每个模板有内容高度上限（max-height 582px），条目数不要超过模板参考中的建议值。
- 图表用内联 SVG 手绘，viewBox 固定 `0 0 420 240`，配色遵循色板。
- 图片用相对路径 `images/xxx.jpg`，无图时删除 `<img>` 标签并调整间距。
- 输出为单文件 HTML，不依赖外部 CSS/JS（字体用系统回退）。
